# Team Contribution Rules

## Branches

Use feature/<short-name>, experiment/<short-name>, or docs/<short-name>. Keep main stable.

## Pull requests

Every pull request must link a GitHub task and include what changed, how it was tested, the exact command used, dataset/configuration/seed details for experiments, screenshots or metrics when output changes, and a privacy check confirming that no raw CCTV, face crops, credentials, or large weights were added.

## Review standard

At least one teammate reviews each pull request. Resolve comments or record why a comment is deferred. Merge only after the smoke test passes.

## Commit style

Use short action-oriented messages such as add tracklet manifest schema, compare pooling methods, or document benchmark license.
